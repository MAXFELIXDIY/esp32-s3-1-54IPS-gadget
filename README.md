# IoT Dev Board — ESP32-S3 + 1.54" IPS

Проєкт прошивки для плати розробки на ESP32-S3 з дисплеєм.

**Плата ідентифікована:** XingZhi Cube 1.54TFT, WiFi-варіант — одна з плат
екосистеми [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32)
(конфіг `main/boards/xingzhi-cube-1.54tft-wifi/config.h` збігається з
розпіновкою, знайденою експериментально). Існує варіант `-ml307` з 4G-модемом
(UART на GPIO 11/12) — металевий слот на платі під SIM-картку.

## Залізо (з фото та маркувань чипів)

| Компонент | Деталі |
|---|---|
| SoC | ESP32-S3 **R8** (QFN56, rev v0.2) — dual-core Xtensa LX7, 8 МБ PSRAM у корпусі (підтверджено esptool) |
| Flash | 16 МБ SPI NOR, quad-режим (на цьому екземплярі — Boya; на продуктовому фото Winbond W25Q128JVSQ) |
| MAC | `10:20:ba:6c:d3:50` |
| Дисплей | 1.54" IPS TFT 240×240, ST7789-сумісний, SPI (розпіновку знайдено перебором, див. нижче) |
| Живлення | USB-C (нативний USB ESP32-S3), роз'єм акумулятора V+/V−, зарядка (LED `CHG`), кнопка `POWER` |
| Кнопки | Ліва = GPIO39, середня = GPIO0 (BOOT), права = GPIO40 — усі active-low, потрібен внутрішній pullup (підтверджено 2026-07-10). POWER — апаратна (вимикає живлення, не GPIO) |
| Інші GPIO | GPIO48 при старті LOW — щось підключено (можливо, адресний RGB LED); GPIO 43/44 (UART0) вільні від кнопок |
| Антена | u.FL роз'єм |
| Слот | microSD/SIM (металевий, по центру) |
| Роз'єми | кілька JST: POWER, GND/VCC/13/12, GND/VCC/11 та ін. |
| Підписані GPIO | 38, 39, 40, 43 (TX0), 44 (RX0), 45, 21, 18, 13, 12, 11, 8, 9, 10 |
| Інше | LED `PWR`, `C3` (червоний компонент зліва — LED?), кварц 40 МГц |

## Розпіновка дисплея (підтверджено 2026-07-09)

| Сигнал | GPIO |
|---|---|
| SCLK | 9 |
| SDA (MOSI) | 10 |
| CS | 14 (перебором знайшли «21», але за конфігом плати CS=14; працює і так і так — лінія, ймовірно, підтягнута активною) |
| DC | 8 |
| RST | 18 |
| Підсвітка (BL) | 13 (active high) |

Контролер не відповідає на RDDID (0x04) — читання ID не працює, визначали
візуальним перебором (`display-probe`). Ініціалізація стандартна для ST7789
(`esp_lcd_new_panel_st7789`), потрібен `invert_color(true)` як для всіх IPS.

**Важливо: панель працює тільки в SPI mode 3** (SCK idle high) — у mode 0
не відповідає взагалі. 40 МГц стабільні (перевірено діагностикою швидкостей).
Повнокадрова плазма через esp_lcd + DMA: ~25 FPS.

## Аудіо (підтверджено 2026-07-10)

- **Динамік**: I2S-підсилювач без enable-піна (тип MAX98357/NS4168):
  DOUT=GPIO7, BCLK=GPIO15, LRCK=GPIO16. 24 кГц / 16 біт / моно — працює.
  Роз'єм «+/−» у правому нижньому куті. PWM-тон на пін не працює — тільки I2S.
- **Мікрофон** (підтверджено: реагує на голос і хлопки): I2S WS=GPIO4,
  SCK=GPIO5, DIN=GPIO6, 16 кГц, 32-бітні слоти (дані в лівому), моно.
  Фізично — MEMS у металевому корпусі біля кнопки «40» / u.FL.
- **RGB-світлодіод WS2812** (підтверджено 2026-07-10): data-пін **GPIO48**,
  порядок кольорів GRB (стандартний), драйвер — компонент
  `espressif/led_strip` через RMT. Фізично — білий корпус із 4 контактами
  під падом 44/RX0.

## Порт

Плата визначається як `/dev/cu.usbmodem2101` (вбудований USB-Serial/JTAG, без окремого UART-моста).

## Збірка / як почати

Потрібен **ESP-IDF v5.5** ([інструкція встановлення](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32s3/get-started/)).

```bash
git clone <URL-цього-репозиторію>
cd <тека>/gadget

# 1. Ключі (файли в .gitignore — впишіть свої):
cp main/groq_key.h.example main/groq_key.h
#    → вставте ключ Groq з https://console.groq.com/keys (для асистента)
#    Wi-Fi у gadget вводиться з пристрою (Налаштування → Wi-Fi), файл не потрібен.

# 2. Збірка і прошивка (порт зазвичай /dev/cu.usbmodemXXXX або /dev/ttyACM0):
. $IDF_PATH/export.sh
idf.py set-target esp32s3
idf.py -p <ПОРТ> flash monitor
```

Перше складання підтягне залежності (LVGL 9, Helix MP3, led_strip) через ESP-IDF
Component Manager автоматично.

**Проєкти в репозиторії:**
- `gadget/` — **основна прошивка** (усе описане нижче). Збирайте саме її.
- `radio/` — окреме інтернет-радіо (Wi-Fi через `wifi_creds.h`: `cp main/wifi_creds.h.example main/wifi_creds.h`).
- `firmware/` — базовий каркас-демо (дисплей + кнопки).
- `display-probe/` — діагностичні скетчі (пошук розпіновки, тести периферії).

## Стан проєкту

- `gadget/` — **головна прошивка** (робочий стіл робота). Головний екран:
  «живе» анімоване обличчя (очі + рот) — кліпає, роззирається, підморгує,
  «розмовляє», примружується, і **повільно дрейфує по екрану** (проти
  вигоряння) — плюс **годинник ГГ:ХХ** (SNTP, часовий пояс Києва,
  синхронізація при кожному підключенні). Утримання центру 5 с на обличчі →
  Асистент. Меню (прокручуване): у хедері **зліва значок Wi-Fi** (сірий/білий,
  вбудований шрифт), **справа заряд батареї** (%, колір за рівнем/заряджанням).
  Застосунки (`APPS[]` у `main.c`):
  - **Асистент (Groq)** (`app_gemini.c`) — голос: мікрофон → WAV → Whisper
    (розпізнавання) → Llama 3.3 → текст на екрані. Клік — озвучити (Google
    TTS через `audio_play_clip`), подвійний клік — новий запит, утримання —
    вихід. RGB-світлодіод показує стан (жовтий=запис, білий=розпізнавання,
    синій=думаю, зелений=готово, червоний=помилка). Ключ Groq у
    `main/gemini_key.h` (`gsk_...`, не публікувати!).
  - **Прогноз погоди** (`app_weather.c`) — Open-Meteo + локація за IP,
    подетально по днях (сьогодні +3), **іконки погоди примітивами LVGL**,
    імовірність опадів/хмарність/вітер. +/− гортають дні. Вантажиться
    ЛИШЕ при відкритті сторінки.
  - **Інтернет-радіо** (`app_radio.c`) — 5 станцій через `audio.c` (I2S),
    панель гучності (спільна з налаштуваннями, зберігається).
  - **Новинна стрічка** (`app_news.c`) — RSS «Української правди»: список по
    10 (довантаження гортанням), відкриття новини з повним текстом.
  - **BLE сканер** (`app_ble.c`, `ble_core.c`) — при вході Wi-Fi off + BT on;
    список (нумерація, сортування за RSSI, до 50, пошук 5 с потім фіксація,
    спінер поки BLE вмикається), дедуплікація за MAC + назвою; активне
    сканування (назви зі scan response); тап → деталі → тап → розшифровка GATT.
    Подвійний клік — новий пошук.
  - **Модулі** (`app_modules.c`) — універсальна колодка на 4-пін роз'ємі
    1.25 мм (GND/VCC/**GPIO12=SCL**/**GPIO11=SDA**): BME280 (клімат, повний
    драйвер), I2C-сканер, цифровий вихід (GPIO11), аналоговий вхід (ADC2 на
    GPIO11). У меню обираєш тип під'єднаного модуля.
  - **Нічник** (`app_light.c`) — RGB-світлодіод як лампа: колір (ліва/права),
    яскравість (центр); світло лишається після виходу.
  - **Налаштування** (`app_settings.c`) — Wi-Fi (пошук/клавіатура/збережені
    мережі з ✓), яскравість, гучність. Усе в NVS (`settings.c`, `netcfg.c`).

  Спільні модулі: `led.c` (WS2812 GPIO48), `battery.c` (ADC2), `netcfg.c`
  (Wi-Fi + SNTP-годинник), `audio.c` (I2S: потік для радіо + `audio_play_clip`
  для TTS через повне декодування в PCM у PSRAM).

  **Енергорежим:** Wi-Fi і BLE взаємно виключні. На головному екрані Wi-Fi
  повністю деініціалізовано (`esp_wifi_deinit`); у меню — вмикається; у
  BLE-сканері — BLE замість Wi-Fi. Це заодно вирішує брак внутрішньої RAM
  (не потрібні обидва радіо разом).

### Непомітні граблі (важливо!)
- **LVGL `lv_label_set_text_fmt` НЕ підтримує `%f`** — float форматувати
  стандартним `snprintf`, тоді `lv_label_set_text`. Інакше числа не видно.
- **Буфери дисплея LVGL — тільки у ВНУТРІШНІЙ RAM** (`MALLOC_CAP_DMA |
  MALLOC_CAP_INTERNAL`). У PSRAM SPI-DMA зависає, коли BLE-контролер вимикає
  кеш → `main` застрягає в `refr_sync_areas`.
- **BLE контролеру треба ~34 КБ безперервної внутрішньої RAM** — тому перед
  `ble_start()` робимо повний `esp_wifi_deinit()` (`netcfg_wifi_stop`).
- **BLE ініціалізація — у окремій задачі**, не в UI-потоці (інакше фриз).
- **Символи LVGL (`LV_SYMBOL_WIFI` тощо)** рендеряться лише вбудованим
  шрифтом (`&lv_font_montserrat_14`), не нашим кириличним.
- **HTTP TX-буфер** для довгих URL (TTS ~700 символів) підняти до 2048,
  інакше `HTTP_CLIENT: Out of buffer`.
- **Батарея:** ADC2 канал 6 (GPIO17), заряджання GPIO38; ADC2 ділиться з
  Wi-Fi, читати рідко й стійко до збоїв (`battery.c`).
- `radio/` — **інтернет-радіо** (працює): HTTP MP3-стрім → буфер 160 КБ у
  PSRAM → декодер Helix MP3 → I2S. LVGL-інтерфейс зі станцією/статусом/
  гучністю, RGB LED показує стан (жовтий = буферизація, зелений = грає,
  червоний = помилка). Керування: ліва/права — станції, середня коротко —
  play/stop, середня довго — режим гучності (ліва/права = ±). 5 станцій
  у `main/main.c` (SomaFM ×2, Radio Paradise, Хіт FM, Радіо ROKS).
  Wi-Fi облікові дані — `main/wifi_creds.h` (локальний файл, не публікувати!).
  Особливості: TLS та Wi-Fi буфери в PSRAM (`CONFIG_MBEDTLS_EXTERNAL_MEM_ALLOC`,
  `CONFIG_SPIRAM_TRY_ALLOCATE_WIFI_LWIP`), кастомна таблиця розділів
  (factory 8 МБ), гучність — програмне масштабування семплів.
- `firmware/` — базовий каркас: **LVGL 9** + esp_lcd (ST7789) + 3 кнопки
  в режимі енкодера (ліва/права = обертання, середня = натиск/редагування),
  підсвітка через LEDC PWM (GPIO13). Працює.
- `display-probe/` — діагностичні прошивки (пошук розпіновки, тест швидкостей
  SPI, монітор кнопок). Стара версія коду — у `main/*.bak`.
- Українські шрифти: `firmware/main/fonts/font_ua_16.c` та `font_ua_20.c` —
  Montserrat Medium з кирилицею, згенеровані `lv_font_conv` (діапазони:
  ASCII, 0x400–0x4FF, тире/лапки, °, ₴). Для інших розмірів — та сама команда
  з іншим `--size` (TTF: JulietaUla/Montserrat на GitHub).
