# IoT Dev Board — ESP32-S3 + 1.54" IPS

Проєкт прошивки для плати розробки на ESP32-S3 з дисплеєм.

**Плата ідентифікована:** XingZhi Cube 1.54TFT, WiFi-варіант — одна з плат
екосистеми [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32)
(конфіг `main/boards/xingzhi-cube-1.54tft-wifi/config.h` збігається з
розпіновкою, знайденою експериментально). Існує варіант `-ml307` з 4G-модемом
(UART на GPIO 11/12) — металевий слот на платі під SIM-картку.

## Залізо (з фото та маркувань чипів)

| Компонент | Деталі |
|---|---|
| SoC | ESP32-S3 **R8** (QFN56, rev v0.2) — dual-core Xtensa LX7, 8 МБ PSRAM у корпусі (підтверджено esptool) |
| Flash | 16 МБ SPI NOR, quad-режим (на цьому екземплярі — Boya; на продуктовому фото Winbond W25Q128JVSQ) |
| MAC | `10:20:ba:6c:d3:50` |
| Дисплей | 1.54" IPS TFT 240×240, ST7789-сумісний, SPI (розпіновку знайдено перебором, див. нижче) |
| Живлення | USB-C (нативний USB ESP32-S3), роз'єм акумулятора V+/V−, зарядка (LED `CHG`), кнопка `POWER` |
| Кнопки | Ліва = GPIO39, середня = GPIO0 (BOOT), права = GPIO40 — усі active-low, потрібен внутрішній pullup (підтверджено 2026-07-10). POWER — апаратна (вимикає живлення, не GPIO) |
| Інші GPIO | GPIO48 при старті LOW — щось підключено (можливо, адресний RGB LED); GPIO 43/44 (UART0) вільні від кнопок |
| Антена | u.FL роз'єм |
| Слот | microSD/SIM (металевий, по центру) |
| Роз'єми | кілька JST: POWER, GND/VCC/13/12, GND/VCC/11 та ін. |
| Підписані GPIO | 38, 39, 40, 43 (TX0), 44 (RX0), 45, 21, 18, 13, 12, 11, 8, 9, 10 |
| Інше | LED `PWR`, `C3` (червоний компонент зліва — LED?), кварц 40 МГц |

## Розпіновка дисплея (підтверджено 2026-07-09)

| Сигнал | GPIO |
|---|---|
| SCLK | 9 |
| SDA (MOSI) | 10 |
| CS | 14 (перебором знайшли «21», але за конфігом плати CS=14; працює і так і так — лінія, ймовірно, підтягнута активною) |
| DC | 8 |
| RST | 18 |
| Підсвітка (BL) | 13 (active high) |

Контролер не відповідає на RDDID (0x04) — читання ID не працює, визначали
візуальним перебором (`display-probe`). Ініціалізація стандартна для ST7789
(`esp_lcd_new_panel_st7789`), потрібен `invert_color(true)` як для всіх IPS.

**Важливо: панель працює тільки в SPI mode 3** (SCK idle high) — у mode 0
не відповідає взагалі. 40 МГц стабільні (перевірено діагностикою швидкостей).
Повнокадрова плазма через esp_lcd + DMA: ~25 FPS.

## Аудіо (підтверджено 2026-07-10)

- **Динамік**: I2S-підсилювач без enable-піна (тип MAX98357/NS4168):
  DOUT=GPIO7, BCLK=GPIO15, LRCK=GPIO16. 24 кГц / 16 біт / моно — працює.
  Роз'єм «+/−» у правому нижньому куті. PWM-тон на пін не працює — тільки I2S.
- **Мікрофон** (підтверджено: реагує на голос і хлопки): I2S WS=GPIO4,
  SCK=GPIO5, DIN=GPIO6, 16 кГц, 32-бітні слоти (дані в лівому), моно.
  Фізично — MEMS у металевому корпусі біля кнопки «40» / u.FL.
- **RGB-світлодіод WS2812** (підтверджено 2026-07-10): data-пін **GPIO48**,
  порядок кольорів GRB (стандартний), драйвер — компонент
  `espressif/led_strip` через RMT. Фізично — білий корпус із 4 контактами
  під падом 44/RX0.

## Порт

Плата визначається як `/dev/cu.usbmodem2101` (вбудований USB-Serial/JTAG, без окремого UART-моста).

## Збірка / як почати

Потрібен **ESP-IDF v5.5** ([інструкція встановлення](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32s3/get-started/)).

```bash
git clone <URL-цього-репозиторію>
cd <тека>/gadget

# 1. Ключі (файли в .gitignore — впишіть свої):
cp main/groq_key.h.example main/groq_key.h
#    → вставте ключ Groq з https://console.groq.com/keys (для асистента)
#    Wi-Fi у gadget вводиться з пристрою (Налаштування → Wi-Fi), файл не потрібен.

# 2. Разова «провізія» секретів у NVS (ключ Groq у бінарник НЕ потрапляє):
. $IDF_PATH/export.sh
idf.py set-target esp32s3
idf.py build -DPROVISION_SECRETS=1 && idf.py -p <ПОРТ> flash   # запис ключа в NVS

# 3. Звичайна збірка/прошивка (без секретів — саме її публікуємо для FOTA):
idf.py build -DPROVISION_SECRETS=0 && idf.py -p <ПОРТ> flash monitor
```

> **Безпека:** ключ Groq зберігається в NVS, а не в прошивці. Звичайна збірка
> (`-DPROVISION_SECRETS=0`) не містить токенів — її можна безпечно публікувати
> для оновлень по Wi-Fi. Ключ у NVS переживає всі OTA-оновлення. Провізію
> (крок 2) достатньо зробити один раз (або при зміні ключа).

Перше складання підтягне залежності (LVGL 9, Helix MP3, led_strip) через ESP-IDF
Component Manager автоматично.

**Проєкти в репозиторії:**
- `gadget/` — **основна прошивка** (усе описане нижче). Збирайте саме її.
- `radio/` — окреме інтернет-радіо (Wi-Fi через `wifi_creds.h`: `cp main/wifi_creds.h.example main/wifi_creds.h`).
- `firmware/` — базовий каркас-демо (дисплей + кнопки).
- `display-probe/` — діагностичні скетчі (пошук розпіновки, тести периферії).

## Стан проєкту

- `gadget/` — **головна прошивка** (робочий стіл робота).

  **Головний екран:** «живе» анімоване обличчя робота (очі + рот) — кліпає,
  роззирається, підморгує, «розмовляє», повільно дрейфує по екрану (проти
  вигоряння) + **годинник ГГ:ХХ** (SNTP, часовий пояс Києва). На простої
  підсвітка **тьмяніє через 60 с** — робот «засинає» (заплющені очі + бульбашки),
  і екран **гасне через 300 с**. Будь-яке натискання будить (перший клік лише
  пробуджує, дію не виконує). Утримання центру 5 с → Асистент.

  **Меню** — карусель великих іконок (одна на екран, плавний свайп): у хедері
  годинник по центру, Wi-Fi зліва, заряд батареї справа. Вибрана іконка
  **пульсує** (плавний масштаб від центру, `lv_anim` на `transform_scale`;
  анімується лише поточна картка). Набір застосунків **налаштовується**
  (Налаштування → Кастомізація меню). На простої підсвітка тьмяніє за 30 с,
  гасне за 60 с.

  **Навігація (3 кнопки):** ліва `–` / права `+` — переміщення (пункти меню,
  курсор у списках, прокрутка), **центр** — вибір/дія, **утримання центру —
  назад / вихід**.

  **Застосунки** (`APPS[]` у `main.c`; порядок фіксований, видимість — у
  кастомізації; Асистент і Налаштування приховати не можна):
  - **Асистент (Groq)** (`app_gemini.c`) — мікрофон → WAV → Whisper → Llama 3.3
    → текст. Контекст розмови (3 останні пари). У відповіді: `–/+` гортати,
    **утримання `+` — новий запит**. RGB-LED показує стан. (Озвучення/TTS
    прибрано — конфліктувало з аудіотрактом.) Ключ Groq — `main/groq_key.h`.
  - **Погода** (`app_weather.c`) — Open-Meteo + локація за IP, по днях,
    іконки примітивами LVGL; `–/+` гортають дні.
  - **Радіо** (`app_radio.c`) — 12 станцій (9 українських + SomaFM ×2, Radio
    Paradise), HTTP-MP3 через `audio.c`; **мют під час буферизації/перемикання**
    (без «зациклювання» DMA); крок гучності ~5 %.
  - **Новини** (`app_news.c`) — RSS «Української правди», довантаження гортанням,
    повний текст новини.
  - **Календар** (`app_calendar.c`) — місяць на сторінку, `–/+` місяці,
    центр — до поточного; сьогодні виділено.
  - **Калькулятор** (`app_calc.c`) — калькулятор **виразів**: увесь вираз на
    табло, пріоритет `* /` над `+ -`, дужки `( )`, backspace `⌫`; обчислення
    на `=`. Курсор `–/+`, центр — натиснути клавішу.
  - **BLE** (`app_ble.c`, `ble_core.c`) — сканер/сніфер: список (стабільний
    порядок, дедуп), розбір реклами (виробник, iBeacon, UUID, Appearance),
    зчитування GATT (hex+ASCII), перехоплення notify. Wi-Fi off на час BLE.
  - **Wi-Fi атака** (`app_wifitools.c`) — скан точок, список клієнтів
    (promiscuous), адресний deauth. **Лише для власних мереж / авторизованого
    тестування.**
  - **Модулі** (`app_modules.c`) — колодка на роз'ємі GND/VCC/**GPIO12=SCL**/
    **GPIO11=SDA**: BME280, I2C-скан, цифровий вихід, ADC.
  - **Нічник** (`app_light.c`) — RGB-LED як лампа (лишається після виходу).
  - **Улюбленець** (`app_pet.c`) — тамагочі-собачка: потреби (їжа/вода/гра)
    спадають з часом і зберігаються в NVS (старіють і у вимкненому стані);
    анімації — біг, стійка на задніх лапах, гавкіт, сум. `–` годувати,
    центр — гра, `+` пити.
  - **Pip-Boy** (`app_pipboy.c`) — Fallout-стиль CRT: вкладки STATUS /
    S.P.E.C.I.A.L. / SKILLS / DATA, анімований маскот, «живі» дані плати.
  - **SD-зонд** (`app_sdprobe.c`) — визначення пінів microSD-слота
    bit-bang-перебором (CMD0+CMD8).
  - **Оновлення / FOTA** (`app_fota.c`) — оновлення прошивки через Wi-Fi.
    Іконка — хмара зі стрілкою вниз. Показує **поточну** версію та **актуальну**
    (`tag_name` останнього GitHub-релізу через API `releases/latest`). Кнопка
    **«Оновити»** внизу активна **лише коли версії різняться**: `+` наводить на
    неї фокус, центр — старт. За наявності оновлення показує вікно **«Що нового»**
    з описом релізу (поле `body` того ж GitHub API). Завантаження образу у неактивний слот
    (`esp_https_ota`) з прогрес-баром; після успіху — ребут у нову прошивку.
    Якщо оновлення немає — центр повторює перевірку. URL образу — стабільне
    посилання на `gadget.bin` з latest GitHub-релізу (в NVS, `FOTA_URL_DEFAULT`
    у `settings.c`). Автоматичний **відкат** на попередній слот, якщо нова
    прошивка не стартує. Докладніше — розділ «FOTA / оновлення по Wi-Fi» нижче.
  - **Налаштування** (`app_settings.c`) — див. нижче.

  **Налаштування:** Wi-Fi (пошук/клавіатура/збережені мережі з ✓), Яскравість,
  Гучність, **Кастомізація меню** (увімк/вимк застосунків — `–/+` курсор,
  центр — перемкнути), **Монітор ресурсів** (RAM / PSRAM / Прошивка / Flash —
  зайнято/всього, оновлення щосекунди). Усе в NVS (`settings.c`, `netcfg.c`).

  Спільні модулі: `led.c` (WS2812 GPIO48), `battery.c` (ADC2), `netcfg.c`
  (Wi-Fi + SNTP + сирі 802.11-операції для Wi-Fi-атаки), `audio.c` (I2S-стрім
  радіо). Багато великих буферів перенесено в PSRAM (`EXT_RAM_BSS_ATTR` /
  `MALLOC_CAP_SPIRAM`, `CONFIG_SPIRAM_ALLOW_BSS_SEG_EXTERNAL_MEMORY`) —
  звільнено ~43 КБ внутрішньої RAM.

  **Енергорежим:** Wi-Fi і BLE взаємно виключні; на головному екрані Wi-Fi
  повністю деініціалізовано (`esp_wifi_deinit`); автозгасання підсвітки з
  таймаутами за екраном (див. вище).

  **FOTA / оновлення по Wi-Fi:**
  - **Таблиця розділів** (`gadget/partitions.csv`): замість одного `factory`
    8 МБ — два OTA-слоти по 4 МБ (`ota_0` @ 0x20000, `ota_1` @ 0x420000) +
    `otadata` (8 КБ). Прошивка ~1.8 МБ, у слоті вільно ~57 %.
    Flash 16 МБ, `CONFIG_ESPTOOLPY_FLASHSIZE_16MB`.
  - **Механізм:** `esp_https_ota` качає образ у неактивний слот, перемикає
    `otadata`, пристрій вантажиться в новий слот. Перший прошив (нова таблиця
    розділів) — по кабелю; далі — по Wi-Fi.
  - **Відкат при збої** (`CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE`): нова прошивка
    стартує в стані `PENDING_VERIFY`; у `app_main` після успішного старту UI
    викликається `esp_ota_mark_app_valid_cancel_rollback()`. Якщо прошивка не
    дійшла до цього (крах/бут-петля) — bootloader відкочується на попередній
    робочий слот.
  - **Джерело образу:** GitHub Releases, стабільне посилання
    `releases/latest/download/gadget.bin` (у прошивці не змінюється між
    релізами). Випуск оновлення: підняти `gadget/version.txt` → `idf.py build`
    → `gh release create vX.Y.Z build/gadget.bin --latest`.

### Непомітні граблі (важливо!)
- **LVGL `lv_label_set_text_fmt` НЕ підтримує `%f`** — float форматувати
  стандартним `snprintf`, тоді `lv_label_set_text`. Інакше числа не видно.
- **Буфери дисплея LVGL — тільки у ВНУТРІШНІЙ RAM** (`MALLOC_CAP_DMA |
  MALLOC_CAP_INTERNAL`). У PSRAM SPI-DMA зависає, коли BLE-контролер вимикає
  кеш → `main` застрягає в `refr_sync_areas`.
- **BLE контролеру треба ~34 КБ безперервної внутрішньої RAM** — тому перед
  `ble_start()` робимо повний `esp_wifi_deinit()` (`netcfg_wifi_stop`).
- **BLE ініціалізація — у окремій задачі**, не в UI-потоці (інакше фриз).
- **Символи LVGL (`LV_SYMBOL_WIFI` тощо)** рендеряться лише вбудованим
  шрифтом (`&lv_font_montserrat_14`), не нашим кириличним.
- **HTTP TX-буфер** для довгих URL (TTS ~700 символів) підняти до 2048,
  інакше `HTTP_CLIENT: Out of buffer`.
- **FOTA з GitHub Releases — підняти ОБИДВА буфери HTTP-клієнта до 4096**
  (`buffer_size` і `buffer_size_tx` у `app_fota.c`). Редіректи GitHub несуть
  підписаний URL із JWT (~1 КБ): він і в заголовку `Location` (RX), і в рядку
  запиту `GET` до `release-assets.githubusercontent.com` (TX). Зі стандартними
  512 Б `esp_https_ota_begin` падає з `ESP_FAIL` / `HTTP_CLIENT: Out of buffer`.
- **Батарея:** ADC2 канал 6 (GPIO17), заряджання GPIO38; ADC2 ділиться з
  Wi-Fi, читати рідко й стійко до збоїв (`battery.c`).
- `radio/` — **інтернет-радіо** (працює): HTTP MP3-стрім → буфер 160 КБ у
  PSRAM → декодер Helix MP3 → I2S. LVGL-інтерфейс зі станцією/статусом/
  гучністю, RGB LED показує стан (жовтий = буферизація, зелений = грає,
  червоний = помилка). Керування: ліва/права — станції, середня коротко —
  play/stop, середня довго — режим гучності (ліва/права = ±). 5 станцій
  у `main/main.c` (SomaFM ×2, Radio Paradise, Хіт FM, Радіо ROKS).
  Wi-Fi облікові дані — `main/wifi_creds.h` (локальний файл, не публікувати!).
  Особливості: TLS та Wi-Fi буфери в PSRAM (`CONFIG_MBEDTLS_EXTERNAL_MEM_ALLOC`,
  `CONFIG_SPIRAM_TRY_ALLOCATE_WIFI_LWIP`), кастомна таблиця розділів
  (factory 8 МБ), гучність — програмне масштабування семплів.
- `firmware/` — базовий каркас: **LVGL 9** + esp_lcd (ST7789) + 3 кнопки
  в режимі енкодера (ліва/права = обертання, середня = натиск/редагування),
  підсвітка через LEDC PWM (GPIO13). Працює.
- `display-probe/` — діагностичні прошивки (пошук розпіновки, тест швидкостей
  SPI, монітор кнопок). Стара версія коду — у `main/*.bak`.
- Українські шрифти: `firmware/main/fonts/font_ua_16.c` та `font_ua_20.c` —
  Montserrat Medium з кирилицею, згенеровані `lv_font_conv` (діапазони:
  ASCII, 0x400–0x4FF, тире/лапки, °, ₴). Для інших розмірів — та сама команда
  з іншим `--size` (TTF: JulietaUla/Montserrat на GitHub).
